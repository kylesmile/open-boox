# SurfaceFlinger Binder interface

Checked on a Note Air 4C, firmware 4.2-rel_04282.

Boox's SurfaceFlinger accepts extra transaction codes on the `SurfaceFlinger` service. The codes are defined as static fields on `android.onyx.ViewUpdateHelper` in `framework.jar`. There is **no permission check**: a plain `adb shell` can call them.

```bash
adb shell service call SurfaceFlinger 16711718     # 0xff0026 APPLY_GC_ONCE: full GC refresh
adb shell service call SurfaceFlinger 16711681 i32 0 i32 0 i32 1860 i32 2480 i32 34
```

`service call` writes the interface token for you. The second command is `REFRESH_SCREEN` with left, top, width, height, mode (`34` = `0x22` = GC16 | UPDATE_MODE_FULL). SurfaceFlinger logs `refresh screen (0, 0 - 2480, 1860) waveform_mode 2 flags 0x0 marker 1`. The panel is natively landscape 2480×1860; SurfaceFlinger rotates portrait coordinates.

## Mode word

Low 4 bits pick the waveform; higher bits are flags.

| Waveform | Value | | Flag | Value |
|---|---|---|---|---|
| INIT | 0x0 | | UPDATE_MODE_FULL | 0x20 |
| DU | 0x1 | | WAIT | 0x40 |
| GC16 | 0x2 | | COMBINE | 0x80 |
| GC4 | 0x3 | | DITHER | 0x100 |
| ANIM (A2) | 0x4 | | INVERT | 0x200 |
| AUTO | 0x5 | | CONVERT | 0x400 |
| REAGL | 0x6 | | DITHER_COLOR_Y1 | 0x800 |
| DU4 | 0x8 | | REAGL_D | 0x1000 |
| REAGL_PLUS | 0x9 | | ONYX_AUTO | 0x1000000 |
| GCC16 (color) | 0xb | | ONYX_GC / APPLY_MONO | 0x2000000 |
| DEEP_GC16 | 0xc | | | |
